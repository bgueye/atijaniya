# SponsorshipBadge

Badge « Parrainage confirmé » avec son explication, obligatoire, au toucher.

**Quand** : sur le profil ou la carte d'un disciple dont le parrainage de mouqaddam est confirmé.

**Le consommateur fournit** : rien ; le libellé et l'explication sont fixes.

**Règles**
- Libellé exact : « Parrainage confirmé ». Jamais « Mouqaddam vérifié » ni « Vérifié ».
- Explication au toucher, mot pour mot : « Ce statut atteste qu'un parrainage a été confirmé au
  sein de la communauté At-Tijaniya. Ce n'est pas une reconnaissance ou une habilitation
  religieuse officielle. »
- Ne jamais afficher le libellé seul, sans le widget.

**Flutter** : existe, `SponsorshipBadge` (`lib/features/mouqaddam/presentation/sponsorship_badge.dart`).
