# StatTile

Tuile de chiffre : un nombre en grand et ce qu'il compte.

**Quand** : chiffres personnels (« 7 jours de suite », « 52 récitations en octobre ») ou
chiffres d'une page (« 9 figures », « 34 lieux »). Par rangées de deux ou trois.

**Le consommateur fournit** : le nombre et sa légende.

**Règles**
- Nombre en Cormorant 28, `emerald` ; légende en 12, `secondary_ink`.
- Variante `dark` (`zaytoune`, nombre `gold_on_dark`) pour le chiffre le plus important d'une rangée.
- Jamais de chiffre décoratif : chaque nombre vient des données.

**Flutter** : à créer dans `lib/core/widgets/stat_tile.dart` (`StatTile`).
