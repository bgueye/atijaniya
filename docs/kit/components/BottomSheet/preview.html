Rattraper son wird · Erreur Doute sur le nombre de répétitionsOn construit sur le nombre le plus bas, celui dont on est sûr. Une fois le wird terminé, on répare par 100 fois « Astaghfirou-llah » avec l'intention de réparer. Source : al-Durra al-Kharida, t. 4, p. 9 ; Munyat al-Murid ; al-Ifada, citée par Zawiya.sn
